# Password Generator Using Python

## Introduction
Password Generator is a simple Python project that generates random passwords based on the user's preferred length.

## Objectives
- To generate random passwords using Python.
- To understand the use of Python modules.
- To practice basic programming concepts.

## Features
- Generates random passwords.
- Includes uppercase and lowercase letters.
- Includes numbers and special characters.
- Allows users to select password length.
- Easy to use.

## Technologies Used
- Python 3
- Secrets Module
- String Module

## Requirements
- Python 3 installed
- No external libraries required

## How to Run
1. Download the repository.
2. Open the project folder.
3. Run the following command:

   `python Password_Generator.py`

4. Enter the desired password length.
5. The generated password will be displayed.

## Example Output

Welcome to Password Generator!

Enter password length: 10

Generated Password: aB7@kL2#pQ

## Conclusion
This project demonstrates the use of Python programming concepts such as strings, loops, modules, and user input to generate random passwords.
